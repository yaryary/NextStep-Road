# NextStep Road

**Clear next steps for unexpected transportation issues.**

NextStep Road is a safety-first incident planner that helps students organize what happened after an unexpected transportation issue. Users select an incident type, answer a few guided questions, and receive a clear general-preparedness checklist for documentation and follow-up.

This project is designed to help make stressful situations feel more manageable. It does not replace emergency services, medical care, legal advice, insurance providers, roadside assistance, or professional vehicle repair.
